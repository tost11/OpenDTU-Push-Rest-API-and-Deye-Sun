# Build Information

The builds are now stored in [releases](https://github.com/tost11/OpenDTU-Push-Rest-API-and-Deye-Sun/releases) on GitHub.

There are 14 prebuilt variants: 10 for 4 MB flash boards (dual slot, web OTA
update), 2 for 8 MB boards and 2 for 16 MB boards.

- Complete matrix with features, add-ons, log level and measured sizes:
  [docs/FeatureSizes.md](../docs/FeatureSizes.md) (section "Release build matrix")
- How the builds are produced: [docs/ReleaseBuilds.md](../docs/ReleaseBuilds.md)

For a description of each feature flag, see the
[Build Flags](../README.md#build-flags) section in the main README.
